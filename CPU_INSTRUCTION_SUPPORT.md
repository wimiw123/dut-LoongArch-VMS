# CPU Instruction Support

## Summary

- Current implemented instruction count: 59
- Core implementation entry: `src/CPU.cpp:47`
- Opcode definitions: `include/decoder.h:88`

## Functional Overview

- 32-bit integer arithmetic, logic, compare, shift, multiply, divide, and modulo
- Byte, halfword, and word load/store through the system bus
- Branch, jump, call, and return control flow
- Basic exception handling: address error, illegal instruction, `SYSCALL`, `BREAK`
- Basic interrupt handling with `CRMD` interrupt-enable control
- Basic CSR access: read, write, and masked exchange
- Simplified two-level page-table MMU using `PGDL`
- CPU reset, cycle counting, register dump, and state dump

## Notes

- Pseudo-instructions generated by the toolchain, such as `move`, `li.w`, `bgtz`, and `bgez`, are not counted as separate ISA instructions here.
- Floating-point state exists in the CPU class, but floating-point instructions are not implemented.
- LL/SC state fields exist in the CPU class, but LL/SC instructions are not implemented.
